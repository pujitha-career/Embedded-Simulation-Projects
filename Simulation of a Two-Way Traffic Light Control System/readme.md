# 🚦 Simulation of a Two-Way Traffic Light Control System

## 📌 Introduction
This mini project focuses on the design and simulation of a **two-way traffic light control system** using Arduino UNO in Proteus ISIS Professional. The system manages traffic flow at an intersection using timed signal control.

---

## 🎯 Objective
- Understand traffic signal control logic  
- Learn multi-output control using a microcontroller  
- Simulate real-time embedded systems  
- Apply timing-based automation concepts  

---

## 🛠️ Software & Tools Used
- 🧠 Arduino UNO R3  
- 💻 Proteus ISIS Professional  
- 🔌 Embedded Systems Concepts  

---

## 🔩 Hardware Components
- 🔴 Red LEDs – 2  
- 🟡 Yellow LEDs – 2  
- 🟢 Green LEDs – 2  
- 🔹 Resistors (330Ω)  
- 🔹 Arduino UNO R3  

---

## 🧩 Circuit Description
- Six LEDs represent traffic signals for two directions  
- Each direction has Red, Yellow, and Green LEDs  
- LEDs are connected to Arduino digital and analog pins through resistors  
- The complete circuit is simulated in Proteus  

---

## ⚙️ Working Principle
- When one direction shows GREEN, the opposite direction shows RED  
- YELLOW signal indicates transition between states  
- Signals change sequentially based on fixed timing delays  
- This ensures smooth and safe traffic flow  

---

## 🌍 Real-Time Example
### 🚦 Road Intersection Traffic Control
- 🔴 Red → Stop  
- 🟡 Yellow → Ready  
- 🟢 Green → Go
