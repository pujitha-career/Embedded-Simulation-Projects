# 🔌 Dual Switch Controlled LED Sequencer Using Arduino Uno

## **📌 Project Overview**
This project is an embedded systems application based on Arduino Uno that controls a sequence of LEDs using two external switches 🔘🔘. Depending on the switch pressed, the LEDs glow in either ascending ⬆️ or descending ⬇️ order. The project demonstrates digital input and output interfacing, control logic, and real-time response in embedded systems.

## **⚙️ Working Principle**
The Arduino continuously monitors the status of two switches. When Switch 1 is pressed, the LEDs are turned ON one by one from LED1 to LED8 with a fixed delay, creating an ascending sequence. When Switch 2 is pressed, the LEDs glow from LED8 to LED1, forming a descending sequence. If no switch is pressed, all LEDs remain OFF .

## **🧩 Block Diagram**
The block diagram consists of an Arduino Uno as the controller, two push button switches as input devices, and eight LEDs as output indicators. The Arduino processes the switch inputs and controls the LED sequence accordingly.

## **🌍 Real-Time Applications**
This project can be used as a running light system in exhibitions and events . It can also serve as a direction indicator in industrial control panels 🏭. The system is useful as a learning platform for beginners to understand embedded system programming and hardware interfacing .

## **💻 Software and Tools Used**
Arduino IDE is used to write and upload the program to the Arduino Uno . Proteus ISIS Professional is used for circuit simulation and testing .

## **✨ Features**
The system supports bidirectional LED sequencing based on user input . It provides real-time response to switch operations and uses a simple and cost-effective hardware setup . The design is easy to understand and suitable for academic and portfolio projects .

The dual switch controlled LED sequencer successfully demonstrates the fundamentals of embedded systems using Arduino Uno . The project provides hands-on experience in digital I/O control and real-time hardware interaction, making it ideal for students and beginners .
