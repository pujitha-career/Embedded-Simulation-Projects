# 🚦 Embedded LED Indicator System

## 📌 Introduction
This mini project presents the **design and simulation of an embedded LED indicator system** using Arduino UNO in Proteus ISIS Professional. The system demonstrates alternate blinking of LEDs based on timing logic, representing real-time indicator applications.

---

## 🎯 Objective
- Understand fundamentals of embedded systems  
- Learn digital output control using a microcontroller  
- Perform embedded system simulation using Proteus  
- Analyze timing-based control logic  

---

## 🛠️ Software & Tools Used
- 🧠 Arduino UNO R3  
- 💻 Proteus ISIS Professional  
- 🔌 Embedded System Concepts  

---

## 🔩 Hardware Components
- 🔹 Arduino UNO R3  
- 🔹 LEDs (2)  
- 🔹 Resistors (220Ω)  
- 🔹 Connecting Wires  

---

## 🧩 Circuit Description
- LEDs are connected to Arduino digital output pins through current-limiting resistors  
- Proper grounding is provided for safe operation  
- The complete circuit is designed and tested using Proteus simulation  

---

## ⚙️ Working Principle
- Digital output pins are configured for LED control  
- Only one LED is activated at a time  
- LEDs glow alternately with a fixed time delay  
- The process repeats continuously, forming an indicator pattern  

---

## 🌍 Real-Time Example
### 🚦 Pedestrian / Warning Indicator System
- 🔴 LED → STOP / ALERT indication  
- 🟢 LED → GO / SAFE indication  
- ⏱️ Timing delay → Signal switching control  

This logic is widely used in:
- Traffic light systems  
- Pedestrian crossings  
- Railway and industrial warning indicators
